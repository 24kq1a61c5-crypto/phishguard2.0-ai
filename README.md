# 🛡️ PhishGuard AI

Real-time phishing & scam detection for links and messages.

## Problem
Over 90% of cyberattacks begin with phishing. Most users cannot tell a malicious link from a safe one.

## Solution
PhishGuard AI analyzes URLs and messages using 15+ heuristics and a scoring engine to flag threats instantly — with a clear explanation of *why* something is risky.

## Features
- 🔗 URL Risk Scanner (HTTPS check, suspicious TLDs, typosquatting, URL shorteners, IP-based URLs)
- 💬 Scam Message Detector (urgency keywords, OTP/KYC bait, lottery scams)
- 📊 0–100 Risk Score with color-coded verdict
- 🧠 Explainable results — shows exactly which rules fired
- ⚡ Runs 100% client-side (no data leaves the browser)
